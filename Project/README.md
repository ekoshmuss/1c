# Веб-интерфейс остатков реагентов и медикаментов (интеграция с 1С)

## Архитектура

```
[ Браузер оператора ]  --HTTP-->  [ Веб-сервер (backend) ]  --HTTP/JSON-->  [ 1С: публикация на веб-сервере ]
  таблица, диаграммы,             Node.js или Python:                        HTTP-сервис в расширении
  отчёты                          - запрос остатков из 1С                    конфигурации (или OData)
                                  - расчёт статуса (зел/жёлт/красн)          -> остатки по складам
                                  - нормы запаса (SQLite)
                                  - выгрузка отчётов Excel/PDF
```

При открытии или обновлении страницы браузер вызывает `GET /api/stock`. Backend сразу берёт свежие остатки из 1С, поэтому нажимать кнопку синхронизации не нужно.

## Что нужно

1. **Со стороны 1С**
   - Опубликовать базу на веб-сервере (Apache или IIS, модуль `wsap24`) с той же машины, где стоит 1С.
   - Создать **расширение конфигурации**, саму типовую конфигурацию не меняем. В расширении сделать HTTP-сервис `stock`, который отдаёт JSON: номенклатура, группа, единица измерения, склад (МОЛ), количество и сумма на дату.
   - Альтернатива: стандартный интерфейс OData, если он включён в конфигурации. Он проще, но запросы к регистрам бухгалтерии через OData менее удобны.
   - Завести отдельного пользователя 1С с правами только на чтение.
2. **Backend** (Node.js или Python) на том же сервере или в той же сети. Он хранит логин к 1С, нормы запаса и пороги, а также формирует отчёты.
3. **Frontend**: таблица, диаграммы, фильтры (макеты лежат в `mockups/`).
4. **Нужные данные**: номер версии конфигурации (БГУ для Казахстана), где ведётся учёт материалов (счета субсчетов запасов, регистр), список складов и групп реагентов, а также нормы запаса по позициям.

## Правило индикатора (настраивается)

Уровень = остаток ÷ норма запаса.

- 🟢 **Достаточно**: от 50%
- 🟡 **Меньше среднего**: от 20 до 50%
- 🔴 **Мало, заказать**: меньше 20%

Вариант: считать «на сколько дней хватит» по среднему расходу за 3 месяца.

## Работа с другого компьютера

Папка `D:\1C` (включая `Project`) синхронизируется с https://github.com/ekoshmuss/1c каждые 5 минут.
На ноутбуке: установить Git, создать пустую папку, положить в неё `setup.ps1` и `sync.ps1` из репозитория и запустить `setup.ps1`. Скрипт подтянет всё с GitHub и включит такую же автосинхронизацию.

# Веб-интерфейс остатков (вариант A — таблица)

Показывает остатки медикаментов и реагентов из 1С (регистр «УчетМедикаментов»), цветной индикатор по норме запаса,
сроки годности по сериям и выгрузку отчётов в Excel. Данные берутся из 1С при каждом открытии/обновлении страницы.

## Состав

| Файл | Назначение |
|---|---|
| `server.js` | веб-сервер: берёт данные из 1С, считает статусы, хранит нормы, отдаёт отчёты |
| `public/index.html` | страница (таблица, фильтры, индикаторы) |
| `.env.example` | образец настроек — скопировать в `.env` |
| `data/norms.json` | нормы запаса (создаётся автоматически) |
| `auth.js`, `public/login.html` | вход по логину и паролю |
| `users.js` | управление пользователями (`data/users.json`, пароли хранятся только в виде хэша) |
| `start.bat` | запуск вручную |
| `install-autostart.ps1` | автозапуск при включении сервера + правило брандмауэра |

## Установка на сервер

1. Установить **Node.js LTS** (версия 18 или новее): https://nodejs.org
2. Скопировать папку `app` на сервер, например в `C:\LabStock`.
3. Скопировать `.env.example` в `.env`, указать `ONEC_USER` и `ONEC_PASS` (пользователь 1С только для чтения).
4. Проверить: запустить `start.bat` и открыть `http://localhost:8080`.
5. Для постоянной работы: PowerShell **от имени администратора** → `.\install-autostart.ps1`.

## Пользователи

В папке приложения на сервере (PowerShell):

```
node users.js add admin admin "Администратор"     # роль admin — может задавать нормы
node users.js add laborant viewer "Лаборант КДЛ"   # роль viewer — только просмотр и отчёты
node users.js list
node users.js disable laborant                     # заблокировать
node users.js add laborant viewer                  # сменить пароль (та же команда)
```

Пароль — не короче 8 символов. После 10 неверных попыток с одного адреса вход блокируется на 15 минут.
Сессия действует 12 часов. Все входы и изменения норм пишутся в окно/журнал сервера.

## Статусы

- 🟢 Достаточно — остаток ≥ 50% нормы
- 🟡 Меньше среднего — 20–50% нормы
- 🔴 Мало, заказать — меньше 20% нормы
- ⚪ Норма не задана — нажмите «задать» в колонке «Норма»
- 🟣 Отрицательный остаток — ошибка учёта в 1С
- Оранжевая дата — срок годности истекает в ближайшие 60 дней, красная — истёк

Пороги меняются в `.env` (`RED_PCT`, `YELLOW_PCT`, `EXPIRY_WARN_DAYS`).

## API

- `GET /api/stock?warehouse=<склад>` — остатки с расчётом статусов
- `POST /api/norms` `{"key":"<склад>|<код>","norm":10}` — сохранить норму (`null` — удалить)
- `GET /api/report.csv?warehouse=<склад>[&type=order]` — отчёт для Excel (все позиции или только к заказу)

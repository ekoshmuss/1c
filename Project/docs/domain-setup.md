# Публикация веб-интерфейса на поддомене (например, sklad.gkib.kz)

## Как это будет работать

```
Пользователь (из любого места)
   │  https://sklad.gkib.kz   ← логин и пароль веб-интерфейса
   ▼
Публичный IP 194.76.125.70 (тот же, что у 1s.gkib.kz)
   │  роутер пробрасывает порт на сервер 192.168.2.3
   ▼
IIS на сервере 192.168.2.3
   ├─ 1s.gkib.kz    → публикация 1С (/new)                 — как сейчас
   └─ sklad.gkib.kz → обратный прокси на http://127.0.0.1:8080 (наше приложение)
                         │
                         ▼  внутри сервера, без выхода в интернет
                      1С: http://192.168.2.3:6536/new/hs/labstock
```

Данные из 1С приложение берёт **внутри сервера**, а не через публичный домен.
Наружу открыт только сайт с формой входа.

## Шаги

### 1. DNS
У регистратора/DNS-хостинга домена `gkib.kz` добавить запись:

| Тип | Имя | Значение |
|---|---|---|
| A | `sklad` | `194.76.125.70` |

(или CNAME `sklad` → `1s.gkib.kz`). Проверка: `nslookup sklad.gkib.kz`.

### 2. IIS: обратный прокси
1. Установить модули IIS **URL Rewrite** и **Application Request Routing (ARR)** (официальные, с сайта Microsoft).
2. В ARR: «Server Proxy Settings» → включить **Enable proxy**.
3. Создать сайт `LabStock` (папка любая, например `C:\LabStock\iis`) с привязкой:
   - тип `http`, **тот же порт, что у 1s.gkib.kz** (на него указывает проброс роутера), **имя узла `sklad.gkib.kz`**.
4. В папке сайта — файл `web.config` (скопировать `app/iis-web.config`).
5. В URL Rewrite сайта: «View Server Variables» → добавить разрешённую переменную `HTTP_X_FORWARDED_PROTO`.

Благодаря привязке по имени узла оба сайта работают на одном порту и не мешают друг другу.

### 3. HTTPS (обязательно для входа через интернет)
1. Бесплатный сертификат Let's Encrypt через программу **win-acme** (`wacs.exe`) — выбрать сайт `LabStock`.
   Для проверки Let's Encrypt должен открываться `http://sklad.gkib.kz` на порту 80.
2. На роутере пробросить порт 443 на сервер (если ещё нет).
3. В `.env` приложения: `TRUST_PROXY=1`, `COOKIE_SECURE=1`, `HOST=127.0.0.1`.
4. Включить в `web.config` правило перенаправления http → https.

> Важно: `1s.gkib.kz` сейчас работает по **http** — пароли пользователей 1С идут через интернет открытым текстом.
> Тот же сертификат/подход стоит применить и к нему.

### 4. Приложение
1. В `.env`: `ONEC_URL=http://192.168.2.3:6536/new/hs/labstock` (после переноса расширения в рабочую базу),
   `ONEC_USER` — отдельный пользователь 1С только для чтения.
2. Создать пользователей веб-интерфейса: `node users.js add ...` (см. `app/README.md`).
3. Автозапуск: `install-autostart.ps1`. При `HOST=127.0.0.1` порт 8080 наружу не открывается.

## Что нужно уточнить
- Доступ к управлению DNS домена `gkib.kz` (кто регистратор/хостинг).
- Доступ к роутеру (какие порты сейчас проброшены на 192.168.2.3: 80 → 6536?).
- Желаемое имя поддомена.
